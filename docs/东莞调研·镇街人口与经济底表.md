# 东莞镇街级人口·就业·出行·发展数据（游戏参数底表）

配套 `scripts/_dg-history-2000-2025.md`。本表只放**数值**，历史事件走那份文件。

口径说明：
- 单位除注明外：人口=人，GDP/工业=亿元，面积=km²，距离=km，时长=分钟。
- 可信度标记：**★** 官方公报/政府网站；**☆** 二手汇编（标注数据源为国家统计局）；**◇** 定性描述（公开报道，非统计值）；**○** 本表据公式推算的估算值；**未查到** = 公开渠道确实没拿到，不做猜测。
- 镇街口径：东莞 32 个镇街（4 街道 + 28 镇）+ 松山湖 + 滨海湾新区 = 官方所称「34 个镇街（园区）」。但**统计上只到 33 个**——滨海湾新区 2017 年才揭牌，全域由长安（交椅湾）、虎门（沙角、威远岛）、沙田部分区域切出，人口/GDP 仍计入原镇，故各表 33 行。

## 6. 不确定项与口径冲突

1. **2000 年 GDP**：当年公布 489.73 亿元；2012 年《东莞统计年鉴》经普修订 820.25 亿元；最新修订序列 831.40 亿元。三个值都能追溯到公开出处，本表用 831.40。**不要混用**。
2. **2010 年 GDP**：当年公布 4246.25 vs 修订 4431.19，差 4.4%，原因同上（经普修订）。
3. **2018 年 GDP**：四经普后由 8278.59 修订为 8818.11。
4. **高埗 2010>2020**：行政区划/统计口径调整，不是人口外流；2010 年六普数据与 2020 年七普不可直接比。
5. **镇街从业人员**：年鉴有，公开渠道无；本表留空标「未查到」，未做估算。
6. **跨镇通勤比例**：官方无公开分镇街 OD 矩阵；只有方向性证据（净流入/睡城），本表标「未查到」。
7. **穗深城际日均客流**：无单线官方数，只有 1.3–1.5 万/日 的广铁日通报区间。
8. **滨海湾新区**：无独立人口/GDP 统计，全部落在长安、虎门、沙田内。
9. **各镇街建成区面积**：只有全市数（1154/1194 km²），逐镇未查到，用 2000 年人口密度代理。
10. **2020 年松山湖**：七普 12.08 万含生态园统筹范围，与「松山湖高新区」行政范围可能不完全一致。

## 东莞调研底稿

这些文件是 `js/data_dg.js` 里数值的来源记录。每条数据都标了来源与可信度（★ 官方统计/公报，☆ 学术论文或规划文件，◇ 媒体报道，○ 推算或内插），改参数前先看这里。

- [东莞调研·历史事件与任务](东莞调研·历史事件与任务.md)——2000–2025 的大事记（20 条 `events`）、四个阶段的史实背景（`eras[].summary`）与 9 条历史任务的依据。
- [东莞调研·历史与时代参数](东莞调研·历史与时代参数.md)——分阶段的通勤、上学、购物、医疗、休闲、枢纽、人口迁移与就业结构数据，以及换算成 `eras[].demand` / `grow` / `corridors` 的建议倍数。
- [东莞调研·镇街人口与经济底表](东莞调研·镇街人口与经济底表.md)——33 个镇街 2000 五普 / 2010 六普 / 2020 七普人口，就业、GDP、通勤、土地四节；`eras[].grow.pop` 与 `centers` 的标定依据。
- [东莞调研·广深接驳口](东莞调研·广深接驳口.md)——27 条与广州、深圳、惠州、中山的轨道接驳（含状态、年份、坐标），`traits` 里 `cityLink` 的 `gates` 依据。
- [东莞调研·交通与拥堵](东莞调研·交通与拥堵.md)——机动车保有量 2000–2024 序列、2015–2024 拥堵指数、通勤时耗与距离、具体堵点、限行/限牌政策与公交分担率；`eras[].goals` 里治堵任务的依据。
- [东莞数据补搜](东莞数据补搜.md)——补搜的四项空白：分镇街跨镇通勤比例、2000–2007 旅游人次、东莞西站客流、医院床位数（含换算与缺口说明）。

## 阶段目标（`eras[].goals`）的数值约定

- **奖励写基准年货币**。引擎在发布时乘当年 `costIndex`（`js/economy.js` 的本城任务循环），所以 2003 年的目标写 128000，玩家实际到手约 20 万。
- **`type: 'zoneCong'` 的地点写 `region`（片区 id）**，发布时由 `Tasks.resolveZone` 解析成该片区最堵（指数口径）或最重（占比口径）的交通小区；降幅写 `drop`，起点与目标由 `Tasks.seedCongestion` 按实测值补。
- **指数口径**（不写 `metric`）适合真堵的片区（长安 1.7、虎门 1.3）；**占比口径**（`metric: 'carShare'`）适合镇域网还没密起来的片区——起点天然接近 100%，随地铁开通下降，永远可达。
- [东莞调研·待补主题](东莞调研·待补主题.md)——还没查到的数据与规划（分镇街通勤/就业/建成区、早年分担率、渡轮客流、3 号线与 28 号线的审批状态），含建议检索词与用途。

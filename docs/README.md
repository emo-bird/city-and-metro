## 地图版本与存档迁移

东莞地图现在是第 **2** 版（`mapVersion: 2, minVersion: 1`），带 `migrate(payload, from)`：

- 区域与地标状态按 id 恢复（引擎 `js/city.js` 的 `byIds`），**增删片区或地标不需要写迁移**；
- 只有「在 `events` 数组中间插入条目」会改变序号，需要在该文件的 `EVENT_INSERTS` 登记 `[启用版本, 插入位置, 插入条数]`，旧存档的 `firedEvents` 会按位置后移；
- 新事件请**追加到末尾**（第 23–30 条就是 2026–2035 的事件，追加不影响老存档）；
- 升版后 `node scripts/_rebuild.mjs` 会更新 `game-manifest.json` 里的 `mapVersion`。

## 阶段目标（`eras[].goals`）的数值约定

- **奖励写基准年货币**。引擎在发布时乘当年 `costIndex`（`js/economy.js` 的本城任务循环），所以 2003 年的目标写 128000，玩家实际到手约 20 万。
- **`type: 'zoneCong'` 的地点写 `region`（片区 id）**，发布时由 `Tasks.resolveZone` 解析成该片区最堵（指数口径）或最重（占比口径）的交通小区；降幅写 `drop`，起点与目标由 `Tasks.seedCongestion` 按实测值补。
- **指数口径**（不写 `metric`）适合真堵的片区（长安 1.7、虎门 1.3）；**占比口径**（`metric: 'carShare'`）适合镇域网还没密起来的片区——起点天然接近 100%，随地铁开通下降，永远可达。

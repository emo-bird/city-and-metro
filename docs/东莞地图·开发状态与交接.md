     --cache dg-pbf --build                                        # 约 20 秒
node scripts/_rebuild.mjs

## 5. 接手必读的 8 个机制坑（都是踩过的）

1. **格网尺寸**：`cfg.W/H` 必须是 8 的倍数，否则 `js/maps.js` 的 `autoZone` 回落到 4、算出小数个交通小区，`js/sim.js` 建数组时抛 `Invalid array length`。（现为 320×240 → ZONE 8 → 1200 个小区）
2. **`data_xx.js` 必须在 `js/geo-index.js` 之后加载**，否则文件开头 `const G = CM.GEOS.dg; if (!G) return;` **静默不注册、不报错**。
3. **片区认领按数组顺序**（`js/city.js:578`，`rr[c] === NONE` 才填）：公园/保护区/园区必须排在镇街**前面**，否则 0 格。
4. **`useMap` 是原地清空 + 赋值**：`for (const k of Object.keys(CM.DATA)) delete CM.DATA[k]; Object.assign(CM.DATA, m.data);` —— 所以**任何「引用 `CM.DATA` 对象本体」的代码都会在切图时炸**。判断当前图的数据请读 `CM.MAPS.dg.data`，读 `CM.DATA` 只在游戏局内有效。
5. **`passOnly` 必须配 `open: null`** 才拦得住设站（`js/metro.js` 的条件是「已锁定 + passOnly」）；只写 `passOnly: true` 无效。
6. **`events` 索引即身份**：存档里 `firedEvents` 记的是事件序号。**在 events 数组中间插入**必须写迁移（本图 `mapVersion 2` 的 `migrate` 就是为 2022 年那两条做的，`EVENT_INSERTS = [[2, 19, 2]]`）。只在末尾追加则不需要。
7. **`eras[].corridors` 只作用于通勤(hw)与购物(sh)**，且 `a/b` 必须是**片区 id**（写错不报错、静默跳过）；`demand.decayHW` 是**乘在引擎年曲线上的倍数**（写 3.4 是语义错误，正确值 0.6–1.2）。
8. **`goals` 的 `reward` 是基准年货币**，发布时引擎乘 `costIndex(发布年)`；`histTasks` 同理。写「当年名义金额」会放大 1.5–3.2 倍。

其余备忘：`reclaim` 填海按 `year` 逐年成陆；`scenic` 片区直接置 `LU.HILL`（无人口岗位、只能走地下）；`places` 是自动命名的数据源（`M.suggestName` 取 800 m 内最近未用地名）；`js/macro.js` 的 `gdp0` 单位是**万元**。

## 8. 环境坑（会反复咬人）

- 会话在 Windows：`bash` 工具其实落到 **pwsh**。**不要用 `|`、`>`、`2>&1`、`Tee-Object`** —— 沙箱拒绝命名管道，报 `Access to the path '\\.\pipe\LOCAL\dotnet_…' is denied`。
- `node -e "…"` 只要含引号嵌套或反斜杠就必坏（`SyntaxError: Invalid or unexpected token`）→ **一律写 `.mjs` 文件再 `node x.mjs`**（`tools/_probe-*.mjs` 就是这套习惯的产物，可以照抄）。
- 单行超大的 `js/geo_*.js`、`js/geo-index.js` 不要 `Get-Content`（会吐几十 MB），用 `read` 带 offset 或 `grep`。
- 浏览器自动化用 ego 工具：`ego_js` 里**不要写长轮询**（Runtime.evaluate 超时），改「短查询 + `ego_wait`」；`CM.game.city` 就绪要约 8 秒。
- `CM.City.LU`、`city.clock` 都不存在（LU 是 `js/city.js` 模块内常量；时间用 `CM.game.year()`）。
- 强刷要换 `?v=`，`location.reload()` 也会重取，但 F5 不一定。
